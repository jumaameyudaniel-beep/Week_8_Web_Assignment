# SpendWise – Personal Budget Tracker

## Project Description

SpendWise is a simple and user-friendly personal budget tracking web application developed to help people manage their money effectively.

The application allows users to record income and expenses, monitor their spending, calculate their remaining balance, and manage their personal finances.

The main goal of SpendWise is to encourage responsible spending and improve financial management habits.

## Technologies Used

- HTML5 – Used to create the structure of the website.
- CSS3 – Used to style and design the application.
- JavaScript – Used to add interactive functionality and perform calculations.
- Local Storage – Used to save transactions in the browser.
- Git – Used for version control.
- GitHub – Used to store and manage project files.
- Netlify – Used to deploy and publish the website online.
